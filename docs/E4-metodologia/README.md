# E3 – Metodologia / Materiais e Métodos

## Mural Indie

O **Mural Indie**, também denominado **Indie ProjectHub**, é um projeto desenvolvido para a disciplina de **Projeto e Desenvolvimento de Sistemas (PDS)** do **Instituto Federal do Paraná (IFPR) – Centro de Referência Ponta Grossa**, no ano de **2026**.

### Objetivo

Esta etapa tem como objetivo apresentar a metodologia utilizada no desenvolvimento do Mural Indie, descrevendo a abordagem de desenvolvimento, as ferramentas e tecnologias adotadas, a arquitetura do sistema e os métodos utilizados para organizar e implementar a plataforma web.

### Conteúdo desta entrega

Esta etapa da documentação contém:

- **Abordagem de desenvolvimento:** utilização da metodologia Scrum, organização das tarefas em etapas, criação de mapa mental e realização de encontros semanais.
- **Ferramentas e tecnologias:** apresentação dos recursos utilizados no desenvolvimento do sistema.
- **Arquitetura do sistema:** descrição do modelo cliente-servidor e da organização dos componentes.
- **Frontend:** implementação e personalização das páginas utilizando WordPress.
- **Backend:** gerenciamento das funcionalidades e dos conteúdos por meio dos recursos do WordPress.
- **Banco de dados:** utilização do Firebase para armazenar informações de usuários, projetos, categorias e publicações.
- **Fluxo de informação:** explicação da comunicação entre usuário, interface web, servidor e banco de dados.
- **Diagramas de arquitetura:** representação visual da estrutura e do funcionamento do sistema.

### Ferramentas e tecnologias

- **WordPress:** criação e gerenciamento do site.
- **Firebase:** armazenamento dos dados.
- **GitHub:** controle de versão e colaboração entre os integrantes.
- **Miro:** organização visual das ideias e planejamento do projeto.
- **Scrum:** metodologia utilizada para organizar o desenvolvimento em etapas.

### Arquitetura do sistema

O sistema utiliza o padrão de arquitetura cliente-servidor, com a interface web responsável pela interação com os usuários, o WordPress responsável pela criação e pelo gerenciamento das páginas e o Firebase destinado ao armazenamento dos dados, por meio da integração necessária entre as tecnologias.
