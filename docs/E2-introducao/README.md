# E2 – Introdução

## Mural Indie

O **Mural Indie** é um projeto desenvolvido para a disciplina de **Projeto e Desenvolvimento de Sistemas (PDS)** do **Instituto Federal do Paraná (IFPR) – Centro de Referência Ponta Grossa**, no ano de **2026**.

### Objetivo

O projeto tem como objetivo desenvolver uma plataforma web que facilitará a divulgação e a descoberta de projetos independentes na cidade de Ponta Grossa. O sistema buscará conectar criadores, investidores, colaboradores e pessoas interessadas em iniciativas locais por meio de um ambiente organizado e de fácil acesso.
