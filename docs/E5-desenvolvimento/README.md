# E5 – Desenvolvimento

## Mural Indie

O **Mural Indie**, também denominado **Indie ProjectHub**, é um projeto desenvolvido para a disciplina de **Projeto e Desenvolvimento de Sistemas (PDS)** do **Instituto Federal do Paraná (IFPR) – Centro de Referência Ponta Grossa**, no ano de **2026**.

### Objetivo

Esta etapa tem como objetivo apresentar o processo de desenvolvimento do Mural Indie, descrevendo a implementação das funcionalidades, a construção das interfaces, a organização das páginas, a integração dos recursos e as etapas realizadas para transformar os requisitos definidos em uma plataforma web funcional.

### Conteúdo desta entrega

Esta etapa da documentação contém:

- **Desenvolvimento das interfaces:** criação e personalização das páginas do sistema, buscando proporcionar uma navegação simples e intuitiva.
- **Página inicial:** apresentação da plataforma e dos projetos independentes disponíveis.
- **Sistema de cadastro e login:** implementação das interfaces de acesso e registro de usuários.
- **Perfil do usuário:** organização das informações pessoais e dos dados relacionados aos projetos.
- **Publicação de projetos:** desenvolvimento dos recursos destinados à divulgação de iniciativas independentes.
- **Pesquisa e descoberta:** organização dos projetos para facilitar a localização e a descoberta de novas iniciativas.
- **Integração com banco de dados:** estruturação do armazenamento das informações de usuários, projetos, categorias e publicações.
- **Testes e ajustes:** verificação das funcionalidades implementadas, identificação de problemas e realização de correções.
- **Resultados do desenvolvimento:** apresentação das funcionalidades desenvolvidas e do funcionamento geral da plataforma.

### Ferramentas e tecnologias

- **WordPress:** utilizado para desenvolver, estruturar e gerenciar as páginas da plataforma.
- **GitHub:** utilizado para organizar arquivos, acompanhar alterações e facilitar a colaboração entre os integrantes.

### Desenvolvimento do sistema

O desenvolvimento do Mural Indie foi realizado de maneira gradual, começando pela estruturação das páginas e pela definição dos elementos visuais. Em seguida, foram trabalhadas as interfaces de acesso, os perfis dos usuários e os espaços destinados à divulgação dos projetos independentes.

A construção da plataforma buscou manter uma organização visual consistente, facilitando a navegação e o acesso às principais funcionalidades. Também foram considerados aspectos como usabilidade, clareza das informações e facilidade de utilização.

### Funcionalidades desenvolvidas

As principais funcionalidades planejadas e implementadas na plataforma incluem:

- Cadastro e acesso de usuários.
- Visualização e edição do perfil.
- Publicação e apresentação de projetos independentes.
- Organização dos projetos por categorias.
- Navegação e descoberta de iniciativas divulgadas na plataforma.
- Exibição de informações e imagens relacionadas aos projetos.

### Banco de dados

O Firebase foi definido como tecnologia para o armazenamento das informações do sistema, contemplando dados de usuários, projetos, categorias e publicações.

Sua utilização tem como finalidade permitir a organização e a recuperação das informações necessárias para o funcionamento das funcionalidades da plataforma, por meio da integração com os demais recursos utilizados no desenvolvimento.

### Testes e validação

Durante o desenvolvimento, foram realizadas verificações das interfaces e das funcionalidades da plataforma, buscando identificar possíveis erros de navegação, problemas de apresentação e falhas nos recursos implementados.

Os ajustes realizados tiveram como objetivo melhorar o funcionamento do sistema, garantir maior consistência entre as páginas e proporcionar uma experiência de utilização adequada aos usuários.
